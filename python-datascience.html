🔬 Data Science & Scientific Supercomputing

Python is the premier language for data science, machine learning, and high-performance computing (HPC). From local data analysis with Pandas to petabyte-scale distributed processing on JASMIN and Azure Databricks, mastering the scientific Python stack is essential for modern technical leadership.

Author's Context: At the Centre for Environmental Data Analysis (CEDA) / JASMIN at STFC, researchers run parallel scientific workflows across petabytes of atmospheric, oceanographic, and climate datasets using this stack.

📦 Core Scientific Python Ecosystem

NumPy

N-dimensional array manipulation with fast C-backed vectorization, broadcasting, and linear algebra routines.

import numpy as np
arr = np.linspace(0, 10, 100)

Pandas

High-performance tabular DataFrames, time series handling, aggregations, pivoting, and SQL-like join operations.

import pandas as pd
df = pd.read_csv('data.csv')

Scikit-Learn & ML

Industry-standard algorithms for regression, classification, clustering, dimensionality reduction, and pipeline cross-validation.

Xarray & NetCDF

N-dimensional labeled arrays essential for climate models, satellite observations, and environmental data (NetCDF4, GRIB, HDF5).

Matplotlib & Seaborn

Publication-ready 2D/3D visualizations, geographical plotting with Cartopy, and interactive dashboard charts.

Dask & PySpark

Distributed computing scaling from multi-core workstations to thousands of nodes across cloud and Slurm clusters.

⚡ Scalable Data Processing Example (PySpark & Databricks)

In high-throughput enterprise pipelines, PySpark processes data stored in Azure Data Lake Storage (ADLS Gen2) or Delta Lake:

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, when, avg

spark = SparkSession.builder \
    .appName("JASMIN_Climate_Analysis") \
    .getOrCreate()

# Load petabyte-scale distributed parquet data
df = spark.read.format("delta").load("/mnt/lake/environmental_metrics")

# Transform: Aggregate anomaly detection
anomalies = df.filter(col("temperature_celsius") > 35.0) \
    .groupBy("station_id", "region") \
    .agg(avg("humidity").alias("mean_humidity")) \
    .orderBy(col("mean_humidity").desc())

anomalies.write.mode("overwrite").parquet("/mnt/lake/processed_anomalies")

🖥️ Running Python on Slurm HPC Clusters (JASMIN Pattern)

To run large Python workflows on a supercomputing cluster like JASMIN, jobs are submitted using Slurm batch scripts:

#!/bin/bash
#SBATCH --job-name=python_hpc_job
#SBATCH --partition=standard
#SBATCH --nodes=1
#SBATCH --ntasks=8
#SBATCH --mem=32G
#SBATCH --time=04:00:00
#SBATCH --output=/work/scratch/chami_%j.out

module load jaspy
source activate my_scientific_env

python3 process_scientific_dataset.py --input /gws/nopw/j04/data --output /work/results

🎯 Summary Checklist for Python Data Practitioners

  • Vectorize: Avoid Python for loops when working with NumPy and Pandas. Leverage vectorized C operations.
  • Chunk Big Data: Use Dask or PySpark when data exceeds available system RAM.
  • Reproducibility: Lock environment dependencies using environment.yml or containerize workloads with Docker/Singularity.
