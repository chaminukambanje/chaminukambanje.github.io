☁️ Exam Blueprint: AZ-104

Exam AZ-104: Microsoft Azure Administrator validates subject matter expertise in implementing, managing, and monitoring an organization’s Microsoft Azure environment, including virtual networks, storage, compute, identity, security, and governance.

Domain Weight Core Technical Focus
Manage Azure identities and governance 20–25% Microsoft Entra ID, Users & Groups, PIM, RBAC roles, Azure Policy & Management Groups
Implement and manage storage 15–20% Storage accounts, Blob access tiers, Lifecycle rules, Azure Files, Storage Sync Service
Deploy and manage Azure compute resources 20–25% Virtual Machines, Availability Zones/Sets, Virtual Machine Scale Sets (VMSS), Azure Containers & AKS
Configure and manage virtual networking 20–25% VNets, Subnets, Peering, Network Security Groups (NSGs), Azure Bastion, VPN Gateway, DNS
Monitor and maintain Azure resources 10–15% Azure Monitor, Log Analytics queries (KQL), Alerts, Action Groups, Azure Backup & Site Recovery

🔑 Domain Deep Dive: Networking & Security

VNet Peering vs VPN Gateway

  • VNet Peering: Low latency, high bandwidth private backbone connection between VNets. Traffic never touches the public internet. Supports global peering.
  • Gateway Transit: Allows a peered VNet to utilize the VPN or ExpressRoute gateway of a hub VNet.

NSGs & Application Security Groups (ASGs)

  • NSG: Contains stateful 5-tuple security rules (Priority 100–4096). Applied at subnet or NIC level.
  • ASG: Allows grouping VMs under descriptive monikers (e.g., WEB_SERVERS, DB_SERVERS) inside NSG rules, eliminating manual IP maintenance.

💾 Storage Management & Lifecycle

Access Tiers

Hot: Frequently accessed data.
Cool: Stored min 30 days.
Cold: Stored min 90 days.
Archive: Lowest storage cost, hours retrieval latency.

Replication Strategies

LRS: 3 copies in single datacenter.
ZRS: Synchronous across 3 zones.
GRS: 3 copies locally + 3 in secondary paired region.

Azure Files & Sync

Server Message Block (SMB) and NFS file shares in the cloud. Azure File Sync caches cloud shares on on-premises Windows Servers.

💡 Essential AZ-104 Exam Tips

  • Role-Based Access Control (RBAC): Role assignments inherit down the hierarchy: Management Group → Subscription → Resource Group → Resource. Deny assignments always override allow assignments.
  • Azure Bastion: Provides secure, seamless RDP/SSH access to VMs directly via the Azure portal over SSL (port 443), without exposing public IP addresses on the VMs.
  • KQL Mastery: Learn basic Kusto Query Language syntax for querying AzureDiagnostics and Perf tables in Log Analytics.
