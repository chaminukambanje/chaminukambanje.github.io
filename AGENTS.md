## 2. Deployment Rules
1. **GitHub Pages Constraint**: This repository MUST remain **public** for GitHub Pages to stay active on the Free tier. Do not change visibility to private.
2. **Commit & Push**: Any changes merged into `main` automatically deploy to GitHub Pages within 1-2 minutes.
3. **Verification**: Always test HTML structure and links before pushing to `origin/main`.
